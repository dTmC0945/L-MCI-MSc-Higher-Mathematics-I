1.4 Determinants and Cramer’s Rule

Determinants [24] Historically, determinants were used long before matrices: A determinant was originally defined as a property of a system of linear equations. The determinant “determines” whether the system has a unique solution, which occurs precisely if the determinant is non-zero. In Europe, solutions of linear systems of two equations were expressed by Cardano in 1545 by a determinant-like entity [†-1] Grattan-Guinness, I. Companion encyclopedia of the history and philosophy of the mathematical sciences (Routledge, 2002). were originally introduced for solving linear systems and therefore has a significant place in their application to wide variety of engineering problems. However, before we tackle them in detail, it is worthwhile to have a good refreshment on the topic.

1.4.1 A Quick Refreshment on Determinants

A determinant of second order is denoted and defined by

D = det ⁡ A = | a11 a12 a21 a22 | = a11a22−a12a21, (1.52)

where we use bars instead of brackets to denote the aforementioned operation is a determinant.

Cramer’s Rule for solving linear systems of two (2) equations in two unknowns is represented as follows:

a11x1 + a12x2 = b1 a21x1 + a22x2 = b2 wherex1 = b1 a12 b2 a22 D = b1a22 − a12b2 D , x2 = a11 b1 a21 b2 D = a11b2 − b1a21 D (1.53)

with D as in Eq. (1.52), provided that D ≠ 0, where the value D = 0 appears for homogeneous systems with nontrivial solutions.

¶ Example 1.22: Cramer’s Rule for Two Equation

If

4x1 + 3x2 = 12 2x1 + 5x2 = −8 (1.54)

then we can calculate the unknowns as:

x1 = | 12 3 −8 5 | = 84 14 = 6,x2 = | 4 12 2 −8 | = − 56 14 = −4. (1.55)

1.4.2 Third-Order Determinants

A determinant of third order can be defined by as follows:

D = | a11 a12 a13 a21 a22 a23 a 31 a 32 a 33 | = a11 | a22 a23 a32 a33 | −a21 | a12 a13 a32 a33 | +a31 | a12 a13 a22 a23 | (1.56)

Note the following. The signs on the right are + −+. Each of the three terms on the right is an entry in the first column of D times its minor, that is, the second-order determinant obtained from D by deleting the row and column of that entry; therefore, for a11 delete the first row and first column, and so on. If we write out the minors in Eq. (1.56), we obtain:

D = a11a22a33 − a11a23a32 + a21a13a32 − a21a12a33 + a31a12a23 − a31a13a22. (1.57)

Cramer’s Rule for Linear Systems of Three Equations

a11x1 + a12x2 + a13x3 = b1 a21x1 + a22x2 + a23x3 = b2 a31x1 + a32x2 + a33x3 = b3 isx1 = D1 D ,x2 = D2 D ,x3 = D3 D where(D ≠ 0) (1.58)

with the determinant D of the system given by Eq. (1.57) and:

D1 = | b1 a12 a13 b2 a22 a23 b3 a32 a33 | ,D2 = | a11 b1 a13 a21 b2 a23 a31 b3 a33 | ,D3 = | a11 a12 b1 a21 a22 b2 a31 a32 b3 | (1.59)

Please observe that D1,D2,D3 are obtained by replacing Columns 1, 2, 3, respectively, by the column of the right sides of Eq. (1.58) .

1.4.3 General Properties of Determinants

There is an attractive way of finding determinants Eq. (1.60) which consists of applying elementary row operations to Eq. (1.60). By doing so we obtain an upper triangular determinant (see Sec. 7.1, for definition with "matrix" replaced by "determinant") whose value is then very easy to compute, being just the product of its diagonal entries. This approach is similar (but not the same!) to what we did to matrices in Sec. 7.3.

Interchanging two rows in a determinant introduces a multiplicative factor of − 1 to the value of the determinant!

¶ Theory 1.12: Behavior of an nth-Order Determinant under Elementary Row Operations

i.
Interchange of two rows multiplies the value of the determinant by − 1.
ii.
Addition of a multiple of a row to another row does not alter the value of the determinant.
iii.
Multiplication of a row by a nonzero constant c multiplies the value of the determinant by c. [26] This holds also when c = 0, but no longer gives an elementary row operation.

An interesting property worth mentioning is det ⁡ (cA) = cn det ⁡ A, and NOT cdet ⁡ A).

¶ Theory 1.13: Further Properties of nth-Order Determinants

i. - iii in Theory 1.12 hold also for columns. (d) Transposition leaves the value of a determinant unaltered. (e) A zero row or column renders the value of a determinant zero. (f) Proportional rows or columns render the value of a determinant zero. In particular, a determinant with two identical rows or columns has the value zero.

It is quite remarkable that the important concept of the rank of a matrix A, which is the maximum number of linearly independent row or column vectors of A (see Sec. 7.4), can be related to determinants. Here we may assume that rank A > 0 because the only matrices with rank 0 are the zero matrices (see Sec. 7.4).

¶ Theory 1.14: Rank in Terms of Determinants

Consider an m × n matrix A = [aik]:

1.
A has rank r ⩾ 1 if and only if A has an r × r submatrix with a nonzero determinant.
2.
The determinant of any square submatrix with more than r rows, contained in A, if such a matrix exists, has a value equal to zero.

Furthermore, if m = n, we have:

3.
An n × n square matrix A has rank n if and only if det ⁡ A ≠ 0.

1.4.4 Cramer’s Rule

Theory 1.14 opens the way to the classical solution formula for linear systems known as Cramer’s rule, which gives solutions as quotients of determinants.

Cramer’s rule is NOT practical in computations for which the methods in Secs, 7.3 and 20.120.3 are suitable. However, Cramer’s rule is of theoretical interest in differential equations (Secs. 2.10 and 3.3) and in other theoretical work that has engineering applications.

¶ Theory 1.15: Cramer’s Theorem

If a linear system of n equations in the same number of unknowns x1,…,xn:

a11x1 + a12x2 + ⋯ + a1nxn = b1 a21x1 + a22x2 + ⋯ + a2nxn = b2 ⋯⋯⋯⋯⋯⋯⋯ = · an1x1 + an2x2 + ⋯ + annxn = bn (1.70)

has a nonzero coefficient determinant D = det ⁡ A, the system has precisely one solution. This solution is given by the formulas

x1 = D1 D ,x2 = D2 D ,⋯,xn = Dn D . (1.71)

where Dk is the determinant obtained from D by replacing in D the kth column by the column with the entries b1,…,bn.

Hence if the system Eq. (1.70) is homogeneous and D ≠ 0, it has only the trivial solution x1 = 0,x2 = 0,…,xn = 0. If D = 0, the homogeneous system also has nontrivial solutions.

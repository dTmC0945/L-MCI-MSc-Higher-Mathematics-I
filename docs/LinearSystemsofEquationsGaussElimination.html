1.2 Linear Systems of Equations Gauss Elimination

We now come to one of the most important use of matrices, that is, using matrices for solving systems of linear equations. We showed informally, in Example 1.1 of Matrices, Vectors: Addition and Scalar Multiplication, how to represent the information contained in a system of linear equations by a matrix, called the augmented matrix. This matrix will then be used in solving the linear system of equations. Our approach to solving linear systems is called the Gauss elimination method.

This method is fundamental to linear algebra, and therefore should be understood thoroughly.

A shorter term for systems of linear equations is just linear systems. Linear systems model many applications in engineering, economics, statistics, and many other areas. Electrical networks, traffic flow, and commodity markets may serve as specific examples of applications.

1.2.1 Linear System, Coefficient Matrix, Augmented Matrix

A linear system of m equations in n unknowns x1,…,xn is a set of equations of the form:

a11x1 + ⋯ + a1nxn = b1 a21x1 + ⋯ + a2nxn = b2 ⋯ ⋮ am1x1 + ⋯ + amnxn = bm. (1.36)

The system is called linear given each variable xj appears in the first power only, just as in the equation of a straight line. a11,…,amn are given numbers, called the coefficients of the system. b1,…,bm on the right are also given numbers. If all the bj are zero, then Eq. (1.36) is called a homogeneous system. If at least one bj is not zero, then Eq. (1.36) is called a nonhomogeneous system.

A solution of Eq. (1.36) is a set of numbers x1,…,xn that satisfies all the m equations. A solution vector of Eq. (1.36) is a vector x whose components form a solution of Eq. (1.36). If the system Eq. (1.36) is homogeneous, it always has at least the trivial solution x1 = 0,…,xn = 0.

Matrix Form of Linear Systems

From the definition of matrix multiplication we see that the m equations of Eq. (1.36) may be written as a single vector equation:

A x = b (1.37)

where the coefficient matrix A = [aik] is the m × n matrix

A = [ a11 a12 ⋯ a1n a21 a22 ⋯ a2n ⋮ ⋮ ⋱ ⋮ a m1 am2 ⋯ a mn ] ,andx = [ x1 ⋮ x n ] andb = [ b1 ⋮ b m ] (1.38)

are column vectors. We assume that the coefficients aik are not all zero, so that A is not a zero matrix. Note that x has n components, whereas b has m components. The matrix

A~ = [ a11 ⋯ a1n b1 ⋮ ⋯ ⋮ ⋮ ⋮ ⋯ ⋮ ⋱ ⋱ ⋱ ⋱ ⋱ ⋱ ⋱ ] (1.39)

is called the augmented matrix of the system Eq. (1.36). The vertical line could be omitted, as we will do later.

It is merely a reminder that the last column of A did not come from matrix A but came from vector b.

Therefore, we augmented the matrix A. Note that the augmented matrix A determines the system Eq. (1.36) completely because it contains all the given numbers appearing in Eq. (1.36) .

¶ Example 1.15: Geometric Interpretation. Existence and Uniqueness of Solutions

If m = n = 2, we have two (2) equations in two (2) unknowns x1,x2, namely:

a11x1 + a12x2 = b1 a21x1 + a22x2 = b2. (1.40)

If we interpret x1,x2 as coordinates in the x1x2-plane, then each of the two equations represents a straight line, and (x1,x2) is a solution if and only if the point P with coordinates x1,x2 lies on both lines. Hence there are three (3) possible cases:

1.
Precisely one solution if the lines intersect
2.
Infinitely many solutions if the lines coincide
3.
No solution if the lines are parallel

If the system is homogenous, Case 1. cannot happen, because then those two straight lines pass through the origin, whose coordinates (0, 0) constitute the trivial solution.

Our simple aforementioned example illustrated that a system given in Eq. (1.36) may have no solution. This leads to such questions as:

Does a given system in Eq. (1.36) have a solution? Under what conditions does it have precisely one solution? If it has more than one solution, how can we characterize the set of all solutions?

First, before looking at this in significant detail, let us discuss an important systematic method for solving linear systems.

1.2.2 Gauss Elimination and Back Substitution

The Gauss elimination method can be explained as follows. [15] ¶ [15]Examples of possible solutions a system of linear equations can take.

Consider a linear system that is in triangular form [16] in full, upper triangular form such as:

2x1 + 5x2 = 2and13x2 = −26

Triangular means all the nonzero entries of the corresponding coefficient matrix lie above the diagonal and form an upside-down 90◦ triangle.

Then we can solve the system by back substitution, that is, we solve the last equation for the variable, x2 = −26/13 = −2, No solution and then work backward, substituting x2 = −2 into the first equation and solving it for x1, obtaining x1 = 1 2(2 − 5x2) = 1 2(2 − 5 · (−2)) = 6. This gives us the idea of first reducing a general system to triangular form. For instance, let the given system be

2x1 + 5x2 = 2 − 4x1+3x2 = −30. where its augmented matrix is [ 2 5 2 −4 3 −30 ]. (1.41)

We leave the first equation as it is. We eliminate x1 from the second equation, to get a triangular system. For this we add twice the first equation to the second, and we do the same operation on the rows of the augmented matrix.

This gives − 4x1 + 4x1 + 3x2 + 10x2 = −30 + 2 · 2, that is,

2x1 + 5x2 = 2 13x2 = −26 Row 2 + 2 Row 1 [ 2 5 2 0 13 −26 ]

where Row 2 + 2 Row 1 means Add twice Row 1 to Row 2 in the original matrix. This is the Gauss elimination [17] for 2 equations in 2 unknowns. giving the triangular form, from which back substitution now give us x2 = −2 and x1 = 6, as before.

Since a linear system is completely determined by its augmented matrix, Gauss elimination can be done by merely considering the matrices, as we have just indicated. We do this again in the next example, emphasizing the matrices by writing them first and the equations behind them, just as a help in order not to lose track.

1.2.3 Elementary Row Operations. Row-Equivalent Systems

The aforementioned Example 1.16 illustrates the operations of the Gauss elimination. These are the first two of three operations, which are called

Elementary Row Operations for Matrices The steps which are as follows:

  • Interchange of two rows

  • Addition of a constant multiple of one row to another row

  • Multiplication of a row by a nonzero constant c.

These operations are for rows, not for columns.

Elementary Operations for Equations The steps which are as follows:

  • Interchange of two equations

  • Addition of a constant multiple of one equation to another equation

  • Multiplication of an equation by a nonzero constant c.

Clearly, the interchange of two equations does not alter the solution set. Neither does their addition because we can undo it by a corresponding subtraction. Similarly for their multiplication, which we can undo by multiplying the new equation by 1/c, since c ≠ 0, producing the original equation.

We now call a linear system S1 row-equivalent to a linear system S2 if S1 can be obtained from S2 by finitely many row operations. This justifies Gauss elimination and establishes the following result.

¶ Theory 1.1: Row-Equivalent Systems

Row-equivalent linear systems have the same set of solutions.

Because of this theorem, systems having the same solution sets are often called equivalent systems. But note well that we are dealing with row operations. No column operations on the augmented matrix are permitted in this context because they would generally alter the solution set.

A linear system given in Eq. (1.36) is called overdetermined if it has more equations than unknowns, as in Example 1.16, determined if m = n, as in Example 1.15, and underdetermined if it has fewer equations than unknowns.

In addition, a system of Eq. (1.36) is called consistent if it has at least one solution, [18] Therefore, one solution or infinitely many solutions. but inconsistent if it has no solutions at all, as x1 + x2 = 1,x1 + x2 = 0 in Example 1.15, Case c.

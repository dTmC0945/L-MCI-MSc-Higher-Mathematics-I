2.3 Eigenbases. Diagonalization. Quadratic Forms

Up to now, we have emphasized properties of eigenvalues.

We now turn our attention to the general properties of eigenvectors. Eigenvectors of an n × n matrix A may form a basis for Rn. If we are interested in a transformation y = Ax, such an “eigenbasis” (basis of eigenvectors)-if it exists-is of great advantage because then we can represent any x in ℝn uniquely as a linear combination of the eigenvectors x1,…,xn, say,

x = c1x1 + c2x2 + ⋯ + cnxn. (2.55)

And, denoting the corresponding [57] not necessarily distinct. eigenvalues of the matrix A by λ1,…,λn, we have Axj = λjxj, so that we simply obtain:

y = Ax = A(c1x1 + ⋯ + cnxn) = c1Ax1 + ⋯ + cnAxn = c1λ1x1 + ⋯ + cnλnxn. (2.56)

This shows that we have decomposed the complicated action of A on an arbitrary vector x into a sum of simple actions [58] i.e., multiplication by scalars on the eigenvectors of A.

This is the point of an eigenbasis.

Now if the n eigenvalues are all different, we do obtain a basis:

¶ Theory 2.27: Basis of Eigenvectors

If an n × n matrix A has n distinct eigenvalues, then A has a basis of eigenvectors

x 1 ,⋯,xn for Rn (2.57)

¶ Example 2.43: Eigenbasis, Nondistinct Eigenvalues, and Nonexsitence

The matrix A = [ 5 3 3 5 ] has a basis of eigenvectors [ 1 1 ], [ 1 −1 ] corresponding to the eigenvalues λ1 = 8, λ2 = 2. [59] For more information please look at Example 2.32. Even if not all n eigenvalues are different, a matrix A may still provide an eigenbasis for Rn. See Example 2.32 in Determining Eigenvalues and Eigenvectors, where n = 3. On the other hand, A may not have enough linearly independent eigenvectors to make up a basis. For instance, A in Example 2.33 is

A = [ 0 1 0 0 ]and has only one eigenvector [ k 0 ]where(k ≠ 0, arbitrary). (2.58)

Actually, eigenbases exist under much more general conditions than those in Theory 2.27. An important case is the following.

¶ Theory 2.28: Symmetric Matrices

A symmetric matrix has an orthonormal basis of eigenvectors for ℝn.

¶ Example 2.44: Orthonormal Basis of Eigenvectors

The first matrix in Example 1 is symmetric, and an orthonormal basis of eigenvectors is [1/ 21/ 2]T,

[1/ 2 − 1/ 2]T■ (2.59)

2.3.1 Similarity of Matrices and Diagonalization

Eigenbases also play a role in reducing A to a diagonal matrix whose entries are the eigenvalues of A. This is done by a similarity transformation, which is defined as follows:

¶ Description: 2.10: Similar Matrices, Similarity Transformation

An n × n matrix A^ is called similar to an n × n matrix A if

A^ = P−1AP (2.60)

for some, nonsingular, n × n matrix P.

This transformation, which gives A^ from A, is called a similarity transformation.

The key property of this transformation is that it preserves the eigenvalues of A:

¶ Theory 2.29: Eigenvalues and Eigenvectors of Similar Matrices

If A^ is similar to A, then A^ has the same eigenvalues as A.

In addition to the previous statement, if x is an eigenvector of A, then y = P−1x is an eigenvector of A^ corresponding to the same eigenvalue.

¶ Example 2.45: Eigenvalues and Vectors of Similar Matrices

Let

A = [ 6 −3 4 −1 ]andP = [ 1 3 1 4 ]. (2.61)

Then

A^ = [ 4 −3 −1 1 ] [ 6 −3 4 −1 ] [ 1 3 1 4 ] = [ 3 0 0 2 ]. (2.62)

Here P−1 was obtained from (4*) in Sec. 7.8 with det ⁡ P = 1. We see that A^ has the eigenvalues λ1 = 3,λ2 = 2. The characteristic equation of A is (6 − λ)(−1 − λ) + 12 = λ2 − 5λ + 6 = 0. It has the roots (the eigenvalues of A) λ1 = 3, λ2 = 2, confirming the first part of Theory 2.29.

We confirm the second part. From the first component of (A − λI)x = 0 we have (6λ)x13x2 = 0. For λ = 3 this gives 3x1 − 3x2 = 0, say x1 = [11]T. For λ = 2, it gives, 4x1 − 3x2 = 0, say, x2 = [34]T. In Theorem 3 we therefore have;

y 1 = P−1x 1 = [ 4 −3 −1 1 ] [ 1 1 ] = [ 1 0 ],y2 = P−1x 2 = [ 4 −3 −1 1 ] [ 3 4 ] = [ 0 1 ]. (2.63)

Indeed, these are eigenvectors of the diagonal matrix A^.

Perhaps we see that x1 and x2 are the columns of P. This suggests the general method of transforming a matrix A^ to diagonal form D by using P = X, the matrix with eigenvectors as columns.

By a suitable similarity transformation we can now transform a matrix A to a diagonal matrix D whose diagonal entries are the eigenvalues of A:

¶ Theory 2.30: Diagonalization of a Matrix

If an n × n matrix A has a basis of eigenvectors, then

D = X−1AX (2.64)

is diagonal, with the eigenvalues of A as the entries on the main diagonal. Here X is the matrix with these eigenvectors as column vectors. Also,

D m = X−1AmXwherem = 2,3,⋯ (2.65)

¶ Example 2.46: Application of Diagonalization

Diagonalize

A = [ 7.3 0.2 −3.7 −11.5 1.0 5.5 1.7 1.2 0.2 ]. (2.66)

The characteristic determinant gives the characteristic equation − λ3 − λ2 + 12λ = 0. The roots (eigenvalues of A) are λ1 = 3, λ2 = −4, λ3 = 0. By the Gauss elimination applied to (A − λI)x = 0 with λ = λ1,λ2,λ3 we find eigenvectors and then X−1 by the GaussJordan elimination (Sec. 7.8, Example 1). The results are:

[ 1 3 1 ], [ 1 −1 3 ], [ 2 1 4 ],X = [ −1 1 2 3 −1 1 −1 3 4 ],X−1 = [ −0.7 0.2 0.3 −1.3 −0.2 0.7 0.8 0.2 −0.2 ]. (2.67)

Calculating AX and multiplying by X−1 from the left, we thus obtain

D = X−1AX = [ −0.7 0.2 0.3 −1.3 −0.2 0.7 0.8 0.2 −0.2 ] [ −3 −4 0 9 4 0 −3 −12 0 ] = [ 3 0 0 0 −4 0 0 0 0 ]■ (2.68)

2.3.2 Quadratic Forms and Transformation to Principal Axes

By definition, a quadratic form Q in the components x1,…,xn of a vector x is a sum of n2 terms, namely,

Q = xTAx = ∑ i=1n ∑ k=1na jkxjxk = a11x12 + a 12x1x2 + ⋯ + a1nx1xn + a21x2x1 + a22x22 + ⋯ + a 2nx2xn ⋯ an1xnx1 + an2xnx2 + ⋯ + annxn2 (2.69)

A = [ajk] is called the coefficient matrix of the form. We may assume that A is symmetric, because we can take off-diagonal terms together in pairs and write the result as a sum of two equal terms; see the following example.

¶ Example 2.47: Quadratic Form and Symmetric Coefficient Matrix
x T A x = [ x1 x2 ] [ 3 4 6 2 ] [ x1 x2 ] = 3x12+4x 1x2+6x2x1+2x22 = 3x 12+10x 1x2+2x22. (2.70)

Here 4 + 6 = 10 = 5 + 5. From the corresponding symmetric matrix C = [cik], where cik = 1 2(aik + aki), thus c11 = 3, c12 = c21 = 5, c22 = 2, we get the same result; indeed,

x T C x = [ x1 x2 ] [ 3 5 5 2 ] [ x1 x2 ] = 3x12+5x 1x2+5x2x1+2x22 = 3x 12+10x 1x2+2x22. (2.71)

Quadratic forms occur in physics and geometry, for instance, in connection with conic sections (ellipses x12/a2 + x22/b2 = 1, etc.) and quadratic surfaces (cones, etc.). Their transformation to principal axes is an important practical task related to the diagonalization of matrices, as follows.

By Theory 2.28, the symmetric coefficient matrix A of Eq. (2.69) has an orthonormal basis of eigenvectors. Hence if we take these as column vectors, we obtain a matrix X that is orthogonal, so that X−1 = XT. From Eq. (2.64) we thus have A = XDX−1 = XDXT. Substitution into Eq. (2.69) gives

Q = xTXDXTx. (2.72)

If we set XTx = y, then, since XTx = X−1, we have X−1x = y and thus obtain

x = Xy (2.73)

Furthermore, in Eq. (2.72) we have xTX = (XTx)T = yT and XTx = y, so that Q becomes simply

Q = yTDy = λ1y12 + λ 2y22 + ⋯ + λ nyn2. (2.74)

This proves the following basic theorem.

¶ Theory 2.31: Principal Axes Theorem

The substitution Eq. (2.73) transforms a quadratic form

Q = xTAx = ∑ i=1n ∑ k=1na jkxjxkwhere(akj = ajk) (2.75)

to the principal axes form or canonical form Eq. (2.74), where λ1,…,λn are the eigenvalues [60] Which are not necessarily distinct. of the symmetric matrix A, and X is an orthogonal matrix with corresponding eigenvectors x1,…,xn, respectively, as column vectors.

¶ Example 2.48: Transformation to Principal Axes and Conic Sections

Find out what type of conic section the following quadratic form represents and transform it to principal axes:

Q = 17x12 − 30x 1x2 + 17x22 = 128. (2.76)

We have Q = xTAx, where

A = [ 17 −15 −15 17 ],x = [ x1 x2 ] . (2.77)

This gives the characteristic equation (17 − λ)2 − 152 = 0. It has the roots λ1 = 2, λ2 = 32. Hence Eq. (2.74) becomes

Q = 2y12 + 32y 22. (2.78)

We see that Q = 128 represents the ellipse 2y12 + 32y22 = 128, that is,

y12 y22 + y22 y22 = 1. (2.79)

If we want to know the direction of the principal axes in the x1x2-coordinates, we have to determine normalized eigenvectors from (A − λI)x = 0 with λ = λ1 = 2 and λ = λ2 = 32 and then use Eq. (2.73). We get

[ 1/ 2 1/2 ]and [ −1/ 2 1/2 ], (2.80)

Therefore

x = Xy = [ 1/ 2 −1/ 2 1/2 1/2 ] [ y1 y2 ] ,x1 = y1/ 2 − y2/ 2 x2 = y1/ 2 + y2/ 2. (2.81)

This is a 45◦ rotation ■

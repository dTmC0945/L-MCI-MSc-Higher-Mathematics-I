1.1 Matrices, Vectors: Addition and Scalar Multiplication

As an organizational note, the fundamental concepts and rules of matrix and vector algebra are introduced in Matrices, Vectors: Addition and Scalar Multiplication and are then followed by linear systems, [3] also called systems of linear equations. a main application, as explained in detail in Linear Systems of Equations Gauss Elimination.

As a gentle beginning to this topic, let us start by taking a leisurely look at matrices before we formalize our discussion. A matrix is a rectangular array of numbers or functions which we will enclose in brackets.

For example,

[ 0.5 2 −7 0 −0.8 26 ], [ a11 a12 a13 a21 a22 a23 a 31 a 32 a 33 ] , [ e−2x 2x4 e8x 23x ], [ a1 a2 a3 ] ,and [ 4 1 5 ] (1.1)

are all matrices. The numbers, or functions, are called entries or, less commonly, elements of the matrix. The first matrix in Eq. (1.1) has two (2) rows, which are the horizontal lines of entries.

Furthermore, it has three (3) columns, which are the vertical lines of entries. The second and third matrices are square matrices, which means that each has as many rows as columns 3 and 2, respectively. The entries of the 2nd matrix have two (2) indices, signifying their location within the matrix.

i.
The first index is the number of the row, and
ii.
the second is the number of the column, so that together the entry’s position is uniquely identified.
For example, a23 [4] This is read as “a two three”. is in Row 2 and Column 3, etc.

The notation is standard and applies to all matrices, including those which are NOT square.

Matrices having only a single row or column are called vectors. Therefore, the 4th matrix in Eq. (1.1) has just one row and is called a row vector. The last matrix in Eq. (1.1) has just one column and is called a column vector. Because the goal of the indexing of entries was to uniquely identify the position of an element within a matrix, one index suffices for vectors, whether they are row or column vectors. Thus, the third entry of the row vector in Eq. (1.1) is denoted by a3.

Matrices are handy for storing and processing data in applications. Consider the following two common examples.

¶ Example 1.1: Linear Systems, a Major Application of Matrices

We are given a system of linear equations, briefly a linear system, such as

4x1 + 6x2 + 9x3 = 6 6x1 − 2x3 = 20 5x1 − 8x2 + x3 = 10 (1.2)

where x1,x2,x3 are the unknowns. We form the coefficient matrix, call it A, by listing the coefficients of the unknowns in the position in which they appear in the linear equations. In the second equation, there is no unknown x2, which means that the coefficient of x2 is 0 and hence in matrix A, a22 = 0, Thus,

A = [ 4 6 9 6 0 −2 5 −8 1 ].We form another matrixA~ = [ 4 6 9 6 6 0 −2 20 5 −8 1 10 ] (1.3)

by augmenting A with the right sides of the linear system and call it the augmented matrix of the system. Since we can go back and recapture the system of linear equations directly from the augmented matrix A~, A~ contains all the information of the system and can therefore be used to solve the linear system.

This means that we can just use the augmented matrix to do the calculations needed to solve the system. [5] This will play an important role in Linear Systems of Equations Gauss Elimination. Meanwhile we can verify using substitution, that the solution is x1 = 3, x2 = 1 2, x3 = −1.

The notation x1,x2,x3 for the unknowns is practical but NOT essential as we could have choose x,y,z or some other letters.

¶ Example 1.2: Sales Figures in Matrix Form

As a useful application we can write sales figures for three (3) products; namely I, II, III, in a store on Monday (Mon), Tuesday (Tues), as a matrix:

A = Mon Tues Wed Thur Fri Sat Sun [ 40 33 81 0 21 47 33 0 12 778 50 50 96 90 10 0 0 27 43 78 56 ] I II III

If the company has 10 stores, we can set up 10 such matrices, one for each store. Then, by adding corresponding entries of these matrices, we can get a matrix showing the total sales of each product on each day ■

1.1.1 General Concepts and Notations

Now it is time to formalize what we just have discussed.

i.
We will denote matrices by capital boldface letters A,B,C,⋯, or by writing the general entry in brackets, i.e., A = [aik], and so on.
ii.
By an m × n matrix [6] This is read as m by n matrix. we mean a matrix with m rows and n columns and remember that rows always come first!

m × n is called the size of the matrix.

Therefore an m × n matrix is of the form

A = [ajk] = | a11 a12 … a1n a21 a22 … a2n ⋮ ⋮ ⋱ ⋮ a m1 am2 … a mn | (1.4)

The matrices in Eq. (1.1) are of sizes 2 × 3, 3 × 3, 2 × 2, 1 × 3, and 2 × 1, respectively.

Each entry in Eq. (1.4) has two (2) subscripts.

The first is the row number and the second is the column number.

Thus a21 is the entry in Row 2 and Column 1. If m = n, we call A an n × n square matrix. Then its diagonal containing the entries a11,a22,…,ann is called the main diagonal of A. Thus the main diagonals of the two square matrices in Eq. (1.1) are a11, a22, a33 and e−x, 4x, respectively.

Square matrices are particularly important, as we shall see. A matrix of any size m × n is called a rectangular matrix; this includes square matrices as a special case.

1.1.2 Vectors

A vector is a matrix with only one row or column, where its entries are called the components of the vector. We will denote vectors by lowercase letters, a,b,⋯ or by its general component in brackets, a = [ai], and so on. [7] It is at this point worth mentioning, different disciplines use different notation to symbolise a vector. The most prominent one is between mathematics, where they use a boldface lowercase character, and introductionary physics/engineer materials uses a normal font lower-case letter with arrow on top of it. Our special vectors in Eq. (1.1) suggest that, a general, row vector is of the form

a = [ a1 a2 ⋯ an ] .For instance,a = [ −3 6 0.2 0 1 ].

A column vector, on the other hand, is of the form

b = [ b1 b2 ⋮ ⋮ ].For example,b = [ 2 1 −9 ]. (1.5)

1.1.3 Addition and Scalar Multiplication of Matrices and Vectors

What makes matrices and vectors really useful and particularly suitable for computers is the fact that we can calculate with them almost as easily as with numbers.

We now introduce rules for addition and for scalar multiplication [8] i.e, multiplication by numbers which were suggested by practical applications.

We first need the concept of equality.

¶ Description: 1.1: Equality of Matrices

Two matrices, namely A = [aik] and B = [bik] are said to be equal, written A = B, if and only if they have the same size and the corresponding entries are equal, that is, a11 = b11, a12 = b12, and so on.

Matrices NOT equal are called different, meaning different sized matrices are always different.

¶ Example 1.3: Equality of Matrices

Let

A = [ a11 a12 a21 a22 ] andB = [ 4 0 3 −1 ]. (1.6)

Then

A = Bif and only ifa11 = 4, a12 = 0, a21 = 3,a22 = −1.
¶ Description: 1.2: Addition of Matrices

The sum of two (2) matrices, namely, A = [ajk] and B = [bjk] of the same size is written as A + B and has the entries ajk + bjk obtained by adding the corresponding entries of A and B.

Matrices of different sizes cannot be added.

As a special case, the sum a + b of two row vectors or two column vectors, which must have the same number of components, is obtained by adding the corresponding components.

¶ Example 1.4: Addition of Matrices and Vectors

If

A = [ −4 6 3 0 1 2 ]andB = [ 5 −1 0 3 1 0 ],thenA+B = [ 1 5 3 3 2 2 ]■

¶ Description: 1.3: Scalar Multiplication

The product of any m × n matrix A = [ajk] and any scalar c is written cA and is the m × n matrix cA = [cajk] obtained by multiplying each entry of A by c.

Here (−1)A is simply written − A and is called the negative of A. Similarly, (−k)A is written written − kA. In addition, A + (−B) is written A − B and is called the difference of A and B.

¶ Example 1.5: Scalar Multiplication

If

A = [ 2.7 −1.8 0 0.9 9.0 −4.5 ],then−A = [ −2.7 1.8 0 −0.9 −9.0 4.5 ],10 9 A = [ 3 −2 0 1 10 −5 ],0A = [ 0 0 0 0 0 0 ].

If a matrix B shows the distances between some cities in miles, then multiplying that matrix with 1,609 (i.e., 1,609B) would give these distances in kilometers.

Rules for Matrix Addition and Scalar Multiplication From the familiar laws for the addition of numbers we obtain similar laws for the addition of matrices of the same size m × n, namely,

i. A + B = B + A ii. (A + B) + C = A + (B + C)(written A + B + C) iii.A + 0 = A iv. A + (−A) = 0. (1.7)

Here 0 denotes the zero matrix, of size m × n„ that is, the m × n matrix with all entries zero. If m = 1 or n = 1, this is a vector, called a zero vector. Therefore matrix addition is commutative and associative. Similarly, for scalar multiplication we obtain the rules

i. c(A + B) = cA + cB ii. (c + k)A = cA + kA iii.c(kA) = (ck)A(written ckA) iv. 1A = A (1.8)

1.1.4 Matrix Multiplication

Matrix multiplication means that one multiplies matrices by matrices. Its definition is standard but may looks artificial and slightly counter-intuitive. Therefore, here, we have to study matrix multiplication carefully.

We wills start, of course, with its definition.

¶ Description: 1.4: [

The product C = AB, in this specific order, of an m × n matrix A = [ajk] times an r × p matrix B = [bjk] is defined if and only if r = n and is then the m × p matrix C = [cik] with entries

cjk = ∑ l=1na jlblk = aj1b1k+aj2b2k+⋯+ajnbnkwhere { j= 1,…,m k= 1,…,p. (1.9)

The condition r = n, which was given in ______ ??_______ ?? , means the 2nd factor, B, must have as many rows as the first factor has columns, namely n. A diagram of sizes that shows when matrix multiplication is possible is as follows:

A B = C [m × n][n × p] = [m × p]. (1.10)

The entry cik in Eq. (1.9) is obtained by multiplying each entry in the jth row of A by the corresponding entry in the kth column of B and then adding these n products.

For instance, c21 = a21b11 + a22b21 + ⋯ + a2nbn1, and so on.

One calls this briefly a multiplication of rows into columns. For n = 3, this is illustrated in Figure 1.1 where we shaded the entries which contribute to the calculation of entry c21 just discussed.

Our aforementioned examples show that in matrix products the order of factors must always be observed very carefully. Otherwise matrix multiplication satisfies rules similar to those for numbers, namely.

i. (kA)B = k(AB) = A(kB) writtenkABorAkB ii. A(BC) = (AB)C written ABC iii.(A + B)C = AC + BC iv. C(A + B) = CA + CB (1.15)

provided A, B, and C are such that the expressions on the left are defined; here, k is any scalar. Eq. (1.15)ii is called the associative law. Eq. (1.15)iii and Eq. (1.15)iv are called the distributive laws.

As matrix multiplication is a multiplication of rows into columns, we can write the defining formula Eq. (1.9) more compactly as

cjk = ajbk,wherej = 1,…,m;andk = 1,…,p, (1.16)

where aj is the jth row vector of A and bk is the kth column vector of B, so that in agreement with Eq. (1.9),

a j b k = [ aj1 aj2 ⋯ ajn ] | b1k ⋮ b nk | = aj1b1k+aj2b2k+⋯+ajnbnk.

1.1.5 The use of Linear Transformations in Multiplication of Matrices

Let us now motivate the unnatural matrix multiplication by its use in linear transformations. For n = 2 variables these transformations are of the form:

y1 = a11x1 + a12x2 y2 = a21x1 + a22x2 (1.21)

and suffice to explain the idea. [11] The general case will be discussed in Vector, and Inner Product Spaces, Linear Transformations. For example, Eq. (1.21) may relate an x1x2-coordinate system to a y1y2-coordinate system in the plane. In vectorial form we can write Eq. (1.21) as

y = [ y1 y2 ] = Ax = [ a11 a12 a21 a22 ] [ x1 x2 ] = [ a11x1 + a12x2 a21x1 + a22x2 ] . (1.22)

Now suppose further that the x1x2-system is related to a w1w2-system by another linear transformation, say,

x = [ x1 x2 ] = Bw = [ b11 b12 b 21 b 22 ] [ w1 w2 ] = [ b11w1 + b12w2 b 21w1 + b22w2 ] . (1.23)

Then the y1y2-system is related to the w1w2-system indirectly via the x1x2-system, and we wish to express this relation directly. Substitution will show that this direct relation is a linear transformation, too, say,

y = Cw = [ c11 c12 c21 c22 ] [ w1 w2 ] = [ c11w1 + c12w2 c21w1 + c22w2 ] . (1.24)

Indeed, substituting Eq. (1.23) into Eq. (1.22), we obtain

y1 = a11(b11w1 + b12w2) + a12(b21w1 + b22w2) = (a11b11 + a12b21)w1 + (a11b12 + a12b22)w2 y2 = a21(b11w1 + b12w2) + a22(b21w1 + b22w2) = (a21b11 + a22b21)w1 + (a21b12 + a22b22)w2

Comparing this with Eq. (1.24), we see that

c11 = a11b11 + a12b21 c12 = a11b12 + a12b22 c21 = a21b11 + a22b21 c22 = a21b12 + a22b22.

This proves that C = AB with the product defined as in Eq. (1.9). For larger matrix sizes the idea and result are exactly the same. Only the number of variables changes.

We then have m variables y and n variables x and p variables w.

The matrices A, B, and C = AB then have sizes m × n, n × p, and m × p, respectively. And the requirement that C be the product AB leads to formula Eq. (1.9) in its general form.

Transposition

We obtain the transpose [12] comes from the Old French transposer, to transfer or remove. of a matrix by writing its rows as columns, or equivalently its columns as rows. This also applies to the transpose of vectors. Therefore, a row vector becomes a column vector and vice versa.

In addition, for square matrices, we can also reflect the elements along the main diagonal, that is, interchange entries that are symmetrically positioned with respect to the main diagonal to obtain the transpose.

Hence a12 becomes a21, a31 becomes a13, and so forth.

The Example 1.11 illustrates these ideas. Also note that, if A is the given matrix, then we denote its transpose by AT.

If

A little more compactly, we can write

[ 5 −8 1 4 0 0 ]T = [ 5 4 −8 0 1 0 ], [ 3 0 7 8 −1 5 1 −9 4 ]T = [ 3 8 1 0 −1 −9 7 5 4 ], (1.26)

Furthermore, the transpose [ 6 2 3 ]T of the row vector [ 6 2 3 ] is the column vector

[ 6 2 3 ]T = [ 6 2 3 ].Conversely, [ 6 2 3 ]T = [ 6 2 3 ]. (1.27)

¶ Description: 1.5: Transposition of Matrices and Vectors

The transpose of an m × n matrix A = [ajk] is the n × m matrix AT [13] This is read as A transpose that has the first row of A as its first column, the second row of A as its second column, and so on. Therefore, the transpose of A in Eq. (1.15) is AT = [aki], written out

A T = [akj] = [ a11 a21 ⋯ am1 a12 a22 ⋯ am2 ⋮ ⋮ ⋱ ⋱ ]. (1.28)

As a special case, transposition converts row vectors to column vectors and conversely.

Transposition gives us a choice in that we can work either with the matrix or its transpose, whichever is more convenient. Rules for transposition are

i. (AT)T = A ii. (A + B)T = AT + BT iii.(cA)T = cAT iv. (AB)T = BTAT. (1.29)

Note the last equation where the transposed matrices are in reversed order.

ii.

Triangular Matrices Upper triangular matrices are square matrices which can have nonzero entries only on and above the main diagonal, whereas any entry below the diagonal must be zero. Similarly, lower triangular matrices can have nonzero entries only on and below the main diagonal. Any entry on the main diagonal of a triangular matrix may be zero or not.

Diagonal Matrices These are square matrices which can have nonzero entries only on the main diagonal.

Any entry above or below the main diagonal must be zero.

If all the diagonal entries of a diagonal matrix S are equal, say, c, we call S a scalar matrix because multiplication of any square matrix A of the same size by S has the same effect as the multiplication by a scalar, that is,

AS = SA = cA (1.33)

In particular, a scalar matrix, whose entries on the main diagonal are all 1, is called a unit matrix [14] This is also known as an identity matrix. and is denoted by In or simply by I. For I, formula Eq. (1.33) becomes:
